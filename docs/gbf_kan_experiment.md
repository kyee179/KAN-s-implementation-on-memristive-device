# Fixed Generalized-Bell Basis KAN Experiment

This experiment tests a second hardware route for KAN edge functions. Instead of using polynomial edge functions generated by Gilbert multipliers, each edge is represented by a fixed bank of generalized bell-shaped basis functions:

```text
G_k(x) = 1 / (1 + |(x - c_k) / a_k|^(2 b_k))
phi_ij(x_i) = sum_k w_ijk G_k(x_i)
```

The basis parameters `a_k`, `b_k`, and `c_k` are fixed. Only the crossbar weights `w_ijk` and node biases are trained.

## Hardware Interpretation

The implementation follows the Dorzhigulov-James generalized bell-function cell idea and the RBF-KAN/FastKAN observation that localized RBF-like bases can replace B-spline bases.

For one layer:

1. Each input node drives a bank of GBF cells.
2. Each GBF cell outputs a current proportional to `G_k(x_i)`.
3. A small TIA converts this current back to a voltage row.
4. The TIA voltages drive rows of a differential RRAM crossbar.
5. Each output column sums the weighted currents, giving:

```text
y_j = sum_i sum_k w_ijk G_k(x_i) + bias_j
```

This is still a KAN because the nonlinear functions live on edges. The important difference from the polynomial path is that high-order powers are not generated by cascaded multipliers. The nonlinear basis is generated directly by GBF cells, then the crossbar performs the weighted summation.

## Code Structure

- `GeneralizedBellKANLayer` and `GeneralizedBellKAN` implement the software model.
- `PhysicalGeneralizedBellKANLayer` models GBF current cells, TIA row-voltage conversion, and differential RRAM weights.
- `PhysicalGeneralizedBellKAN` stacks these physical layers.
- `kan_memristor.experiments.gbf_kan` trains the software model, maps it to physical RRAM conductances, and reports resource/energy estimates.

The fixed basis defaults are:

```text
num_basis = 9
centers = uniform grid over [-1, 1]
width = 1.5 * center_spacing
slope b = 2.0
```

## Command

```powershell
python -m kan_memristor.experiments.gbf_kan `
  --datasets complicated_function taglietti_yinyang `
  --num-basis 9 `
  --slope 2.0 `
  --epochs 150 `
  --n-train 2048 `
  --n-test 2048 `
  --batch-size 256 `
  --learning-rate 3e-3 `
  --n-states 64 `
  --inter-layer-normalization tanh `
  --normalization-gain 1.0 `
  --output-dir outputs/gbf_kan_fixed_basis
```

## Results

| Dataset | Stage | Result | GBF cells | TIAs | Memristors | Energy/sample |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| Complicated function | Software | MSE `0.00515` | - | - | - | - |
| Complicated function | Physical mapped | MSE `0.00781` | `306` | `306` | `5472` | `12.05 pJ` |
| Taglietti yin-yang | Software | Accuracy `98.83%` | - | - | - | - |
| Taglietti yin-yang | Physical mapped | Accuracy `98.83%` | `126` | `126` | `648` | `3.11 pJ` |

The software-to-physical gap is small because the GBF basis itself is fixed and the physical mapping only quantizes the linear crossbar coefficients. This is the opposite of the complete polynomial path, where the Gilbert multiplier transfer function changed the actual basis functions and produced a large software-to-physical gap.

## Interpretation

This method is currently the best physical KAN route tested in the project.

Advantages:

- No cascaded high-power multiplier chain is required.
- The nonlinear basis is naturally localized, similar to RBF/FastKAN bases.
- Fixed `a,b,c` makes training simple and hardware mapping stable.
- Physical mapping remains close to software even with 64 RRAM states.
- The classification result is much better than the polynomial KAN experiments.

Costs and limitations:

- It needs one GBF cell and one TIA for every input-feature/basis pair in every layer.
- The RRAM crossbar is larger than the polynomial basis for the same layer width because each edge has 9 basis weights.
- The current GBF cell model is behavioral: it uses the mathematical GBF shape and paper-level power/area assumptions rather than a transistor-level SPICE fit.
- Since `a,b,c` are fixed, basis placement must be chosen carefully. A later experiment can sweep `num_basis`, width, and slope.

The next recommended experiment is a basis sweep over `num_basis = 5, 7, 9, 13` and `slope = 1, 2, 3`, while still keeping `a,b,c` fixed. This should identify the smallest GBF bank that preserves accuracy and reduces GBF/TIA count.
